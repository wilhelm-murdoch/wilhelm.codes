# wilhelm.codes

This repository holds the discussions for the blog at https://wilhelm.codes.

The blog uses [Giscus](https://giscus.app). Giscus stores each comment thread as a GitHub Discussion in this repository. This repository exists for that reason only.

## What is here
- The comment threads, in the Discussions tab.
- This file.

## What is not here
The site source is not here. The code moved to a private forge. This repository keeps no source, no history and no build pipeline.

## Comments
To read a comment or to write a comment, open a post on https://wilhelm.codes. Use the comment box at the end of the post. The box writes to the Discussions tab through Giscus. You need a GitHub account to write a comment.
